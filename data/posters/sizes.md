# Poster Sizes
All production US vintage star wars 1 sheets should always be 27x41 inches. Modern US one sheets are 1 inch shorter 27x40 but that change happened after ROTJ premiered so any US 1 sheet pre-special edition star wars poster should be 27x41.  

Posters came in the following sizes:

| Name | dimensions (size in inches)|
| ---- | ---- |
| one sheet | 27x41 |
| half sheet | 22x28|
| insert | 14x36|
| Window Box | 30x40|
| 40x60 | 40x60 |
| 6 sheet | 81x81 |
| 7 sheet | 81 x 84 |
| 24 sheet | 106 x 234 |
